模型性能测试接口 · 测试任务生命周期

测试任务生命周期

创建异步模型性能测试，并通过轮询查询进度、取消或删除任务，以及导出 Markdown/CSV 报告。全局同一时间只允许一个测试任务运行。

该接口不校验身份。开启局域网访问后，任何能访问 API 端口的客户端都可以启动、取消、删除测试，并读取本机路径和运行端口。

接口地址列表

POST /api/benchmarks
GET /api/benchmarks?status=succeeded&limit=50&offset=0
GET /api/benchmarks/:id
POST /api/benchmarks/:id/cancel
DELETE /api/benchmarks/:id
GET /api/benchmarks/:id/export?format=markdown|csv

请求示例 POST /api/benchmarks

请求示例 
{
  "model_name": "qwen3.5-9b",
  "variants": ["standard"],
  "context_sizes": [4096],
  "warmup_count": 0,
  "repeat_count": 1,
  "request": {
    "user_prompt": "Please respond with a short benchmark-friendly answer.",
    "max_tokens": 256,
    "stream": true,
    "timeout_seconds": 1800
  }
}

轮询任务状态

创建请求返回 202 和 Location 后，轮询详情接口，直到 status 为 succeeded、failed 或 canceled。

HTTP 响应头 
HTTP/1.1 202 Accepted
Location: /api/benchmarks/8bfc2bb9-2a31-4c23-9306-4dd6a92f97dc
GET 请求示例 
GET /api/benchmarks/8bfc2bb9-2a31-4c23-9306-4dd6a92f97dc
轮询响应 
{
  "id": "8bfc2bb9-2a31-4c23-9306-4dd6a92f97dc",
  "status": "running",
  "summary": {
    "total_cases": 1,
    "succeeded": 0,
    "failed": 0,
    "canceled": 0
  },
  "cases": []
}

状态码

  • 202Benchmark queued
  • 204Benchmark record deleted
  • 400Invalid JSON, config, filter, pagination, or export format
  • 404Benchmark run not found
  • 409Another benchmark is active, or an active run cannot be deleted
  • 500Internal storage or service error
MinerU 兼容接口 · 同步文件解析

同步文件解析

兼容 MinerU 开源版和 Cherry Studio OpenMinerU 处理器的同步 multipart 接口。该接口位于服务根路径，不带 /v1。

POST /file_parse

参数表

参数名类型必填描述
filesfile[]是一个或多个 files 文件；单文件上限 200 MiB，请求上限 1 GiB。
backendstring否pipeline 或 hybrid-engine；缺省时读取系统设置中的 MinerU 默认解析模式。
effortstring否medium 或 high，默认 medium。
formula_enableboolean否是否启用公式识别，默认 true。
parse_methodstring否当前仅支持默认值 auto。
lang_liststring[]否当前仅支持默认语言 ch。
table_enableboolean否当前仅支持默认值 true。
image_analysisboolean否当前仅支持默认值 true。
return_mdboolean否返回 Markdown，默认 true。
return_imagesboolean否返回提取图片，默认 false。
response_format_zipboolean否返回 application/zip，默认 false。
return_original_fileboolean否ZIP 中包含原文件，默认 false。
start_page_idinteger否当前仅支持默认值 0。
end_page_idinteger否当前仅支持默认值 99999。
server_urlstring否第一阶段不支持，必须省略或留空。
return_middle_jsonboolean否当前仅支持默认值 false。
return_model_outputboolean否当前仅支持默认值 false。
return_content_listboolean否当前仅支持默认值 false。
client_side_output_generationboolean否当前仅支持默认值 false。

curl 请求示例

curl 
curl -X POST "http://localhost:8084/file_parse" \
 -F "files=@document.pdf" \
 -F "backend=pipeline" \
 -F "return_md=true" \
 -F "return_images=true" \
 -F "response_format_zip=true" \
 --output results.zip

ZIP 响应结构

zip 目录 
document/auto/document.md
document/auto/images/figure.png
document/auto/document_origin.pdf

JSON 响应结构

响应示例 
{
  "backend": "pipeline",
  "version": "0.1.7",
  "results": {
    "document": {
      "md_content": "# Document",
      "images": {"figure.png": "data:image/png;base64,..."}
    }
  }
}

OpenAI 兼容接口 · 对话补全

对话补全

发送对话请求，获取 AI 回复。

POST /v1/chat/completions

参数

参数名类型必填描述
modelstring是模型名称
messagesarray是对话消息列表
temperaturenumber否采样温度
streamboolean否是否使用流式响应
reasoning_effortstring否OpenAI Chat Completions 兼容推理级别，可选值：low、medium、high；本地 llama.cpp 会映射到模板参数
thinking_enabledboolean否Herdsman 兼容扩展：为支持的模型启用或关闭思考模式；本地 llama.cpp 会映射为 enable_thinking
thinking_tokensnumber否Herdsman 兼容扩展：思考 token 预算；本地 llama.cpp 会映射为 reasoning_budget

请求示例

请求头 
POST /v1/chat/completions
Content-Type: application/json
请求体 
{
  "model": "llama3-8b",
  "messages": [
    {
      "role": "user",
      "content": "Hello, how are you?"
    }
  ],
  "temperature": 0.7,
  "reasoning_effort": "high",
  "stream": true
}

流式响应示例

响应 
{
  "id": "chatcmpl-123",
  "object": "chat.completion.chunk",
  "created": 1677858242,
  "model": "llama3-8b",
  "choices": [
    {
      "index": 0,
      "delta": {
        "role": "assistant",
        "content": "I'm fine, thank you!"
      },
      "finish_reason": null
    }
  ]
}
