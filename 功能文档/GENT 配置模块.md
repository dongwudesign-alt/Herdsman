# GENT 配置模块&#x20;

## 一、Agent 一键配置

核心能力：将 **Token Router 网关地址、模型信息、鉴权信息** 自动写入各类 Agent 本地配置文件。

### 支持 Agent 列表

1. **FlowyAIPC**：按钮【配置】
2. **OpenClaw**：按钮【配置】
3. **Hermes Agent**：按钮【配置】
4. **Claude Code**：按钮【配置】
5. **Codex**：按钮【配置】
6. **OpenCode**：按钮【配置】
7. **CodeBuddy**：按钮【配置】
8. **WorkBuddy**：按钮【配置】

> 区分说明：
>
> * 【重新配置】：支持覆盖更新已有配置
> * 【一键配置】：初始化写入网关、模型、鉴权参数
> * **已连通** - 状态标签：🟢 已连通
>   - 按钮：【刷新】作用：重新下发最新网关、鉴权、模型配置覆盖本地文件。
> * **配置异常** - 状态标签：🟡 连接异常
>   - 按钮：【配置】
> * **未配置** - 状态标签：🔴 未连接
>   - 按钮：【配置】

## 二、WSL2 环境自动配置

1. 自动检测当前正在运行的 WSL 发行版，扫描内部已安装的 Agent
2. 自动写入 Token Router 网关地址至 WSL 内 Agent 配置： 优先使用 `localhost`连通异常时自动切换 Windows 主机 IP
3. 操作入口：【重新检测】按钮，手动触发 WSL 环境扫描
