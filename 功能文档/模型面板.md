## 二、云端模型列表（核心能力）

提供多厂商大模型接入，统一接口地址 `https://server.flowyaipc.cn/claw/v1`，支持选择切换模型：

* Auto（自动调度）
* claude-fable-5.0
* claude-opus-4.7 / 4.8 / 5.0
* Deepseek-v4-flash
* Deepseek-v4-pro
* gemini-3.5-flash
* GLM-5、GLM-5.2
* GPT5.5
* GPT5.6-Luna / Sol / Terra
* Kimi-K2.5、Kimi-K2.6
* Minimax-M2.7、Minimax-M3
* Qwen3.7-max、Qwen3.7-plus

> 每个模型标注上下文窗口上限（1M / 262K / 203K / 205K 等），选中模型高亮区分

## 三、配额与认证模块（限流管控）

1. **开关：启用云端 Token 配额** 关闭状态：云端 Token 不限量开启状态：启用 5 小时滑动窗口限额
2. **Token 预算滑块调节** 调节区间：10K \~ 1T约束规则：5 小时滑动窗口内云端 Token 消耗上限
