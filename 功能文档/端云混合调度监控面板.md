# 三、TOKEN 趋势面板

一、图表区域功能

1. **时间维度切换**：支持 24 小时 / 7 天 / 30 天三种统计周期视图
2. **数据刷新**：手动点击【刷新】按钮，更新趋势图表数据
3. **时序趋势图表**：可视化展示不同时间段 TOKEN 消耗走势，横轴为时间戳

二、模型统计列表字段

1. **模型标识**：区分部署类型（云端）、模型标识（auto）
2. **输入 TOKEN**：统计累计输入 token 总量
3. **输出 TOKEN**：统计累计模型返回输出 token 总量
4. **缓存命中 TOKEN**：统计命中上下文缓存节省的 token 数量
5. **最近使用**：记录该模型最后一次调用时间

三、业务指标说明

* 可直观区分输入 / 输出 Token 消耗，观测缓存利用情况
* 支持按时间周期查看 Token 消耗变化，用于用量监控、成本统计
