## 模型性能测试接口

### 测试任务生命周期

> 创建异步模型性能测试，并通过轮询查询进度、取消或删除任务，以及导出 Markdown/CSV 报告。全局同一时间只允许一个测试任务运行。

⚠️安全提示：该接口不校验身份。开启局域网访问后，任何能访问 API 端口的客户端都可以启动、取消、删除测试，并读取本机路径和运行端口。

**接口地址列表**

```
POST  /api/benchmarks
GET   /api/benchmarks?status=succeeded&limit=50&offset=0
GET   /api/benchmarks/:id
POST  /api/benchmarks/:id/cancel
DELETE /api/benchmarks/:id
GET   /api/benchmarks/:id/export?format=markdown|csv
```

**请求示例 POST /api/benchmarks**

```
{
  "model_name": "qwen3.5‑9b",
  "variants": ["standard"],
  "context_sizes": [4096],
  "warmup_count": 0,
  "repeat_count": 1,
  "request": {
    "user_prompt": "Please respond with a short benchmark‑friendly answer.",
    "max_tokens": 256,
    "stream": true,
    "timeout_seconds": 1800
  }
}
```

**轮询任务状态**

> 创建请求返回 202 和 Location 后，轮询详情接口，直到 status 为 succeeded、failed 或 canceled。

HTTP 响应头：

`HTTP/1.1 202 Accepted`

`Location: /api/benchmarks/8bfc2bb9‑2a31‑4c23‑9306‑4dd6a92f97dc`

GET 请求示例：`GET /api/benchmarks/8bfc2bb9‑2a31‑4c23‑9306‑4dd6a92f97dc`

```
{
  "id": "8bfc2bb9‑2a31‑4c23‑9306‑4dd6a92f97dc",
  "status": "running",
  "summary": {
    "total_cases": 1,
    "succeeded": 0,
    "failed": 0,
    "canceled": 0
  },
  "cases": []
}
```

**状态码**

* 202 Benchmark queued
* 204 Benchmark record deleted
* 400 Invalid JSON, config, filter, pagination, or export format
* 404 Benchmark run not found
* 409 Another benchmark is active, or an active run cannot be deleted
* 500 Internal storage or service error

## MinerU 兼容接口

### 同步文件解析

> 兼容 MinerU 开源版和 Cherry Studio OpenMinerU 处理器的同步 multipart 接口。该接口位于服务根路径，不带 /v1。

`POST /file_parse`

**参数表**

表格

| **参数名**                          | **类型**    | **必填** | **描述**                                              |
| -------------------------------- | --------- | ------ | --------------------------------------------------- |
| files                            | file\[]   | yes    | 一个或多个 files 文件；单文件上限 200 MiB，请求上限 1 GiB。            |
| backend                          | string    | no     | pipeline 或 hybrid‑engine；缺省时读取系统设置中的 MinerU 默认解析模式。 |
| effort                           | string    | no     | medium 或 high，默认 medium。                            |
| formula\_enable                  | boolean   | no     | 是否启用公式识别，默认 true。                                   |
| parse\_method                    | string    | no     | 当前仅支持默认值 auto。                                      |
| lang\_list                       | string\[] | no     | 当前仅支持默认语言 ch。                                       |
| table\_enable                    | boolean   | no     | 当前仅支持默认值 true。                                      |
| image\_analysis                  | boolean   | no     | 当前仅支持默认值 true。                                      |
| return\_md                       | boolean   | no     | 返回 Markdown，默认 true。                                |
| return\_images                   | boolean   | no     | 返回提取图片，默认 false。                                    |
| response\_format\_zip            | boolean   | no     | 返回 application/zip，默认 false。                        |
| return\_original\_file           | boolean   | no     | ZIP 中包含原文件，默认 false。                                |
| start\_page\_id                  | integer   | no     | 当前仅支持默认值 0。                                         |
| end\_page\_id                    | integer   | no     | 当前仅支持默认值 99999。                                     |
| server\_url                      | string    | no     | 第一阶段不支持，必须省略或留空。                                    |
| return\_middle\_json             | boolean   | no     | 当前仅支持默认值 false。                                     |
| return\_model\_output            | boolean   | no     | 当前仅支持默认值 false。                                     |
| return\_content\_list            | boolean   | no     | 当前仅支持默认值 false。                                     |
| client\_side\_output\_generation | boolean   | no     | 当前仅支持默认值 false。                                     |

**curl 请求示例**

```
curl -X POST "http://localhost:8084/file_parse" \
‑F "files=@document.pdf" \
‑F "backend=pipeline" \
‑F "return_md=true" \
‑F "return_images=true" \
‑F "response_format_zip=true" \
‑‑output results.zip
```

**ZIP 响应结构**

```
document/auto/document.md
document/auto/images/figure.png
document/auto/document_origin.pdf
```

**JSON 响应结构**

```
{
  "backend": "pipeline",
  "version": "0.1.7",
  "results": {
    "document": {
      "md_content": "# Document",
      "images": {"figure.png": "data:image/png;base64,..."}
    }
  }
}
```

**Cherry Studio 配置**

> 选择 OpenMinerU 处理器，将 API Host 设置为上方服务根 URL。API Key 可留空；发送 Authorization 时 Herdsman 也会忽略。
>
> 地址示例：`http://localhost:8084`

## OpenAI 兼容接口

### 对话补全

> 发送对话请求，获取 AI 回复
>
> `POST /v1/chat/completions`

**参数**

表格

| **参数名**           | **类型**  | **必填** | **描述**                                                                   |
| ----------------- | ------- | ------ | ------------------------------------------------------------------------ |
| model             | string  | √      | 模型名称                                                                     |
| messages          | array   | √      | 对话消息列表                                                                   |
| temperature       | number  | ×      | 采样温度                                                                     |
| stream            | boolean | ×      | 是否使用流式响应                                                                 |
| reasoning\_effort | string  | ×      | OpenAI Chat Completions 兼容推理级别，可选值：low、medium、high；本地 llama.cpp 会映射到模板参数 |
| thinking\_enabled | boolean | ×      | Herdsman 兼容扩展：为支持的模型启用或关闭思考模式；本地 llama.cpp 会映射为 enable\_thinking         |
| thinking\_tokens  | number  | ×      | Herdsman 兼容扩展：思考 token 预算；本地 llama.cpp 会映射为 reasoning\_budget            |

**请求示例**

```
POST /v1/chat/completions
Content‑Type: application/json
```

```
{
  "model": "llama3‑8b",
  "messages": [
    {
      "role": "user",
      "content": "Hello, how are you?"
    }
  ],
  "temperature": 0.7,
  "reasoning_effort": "high",
  "stream": true
}
```

**流式响应示例**

```
{
  "id": "chatcmpl‑123",
  "object": "chat.completion.chunk",
  "created": 1677858242,
  "model": "llama3‑8b",
  "choices": [
    {
      "index": 0,
      "delta": {
        "role": "assistant",
        "content": "I'm fine, thank you!"
      },
      "finish_reason": null
    }
  ]
}
```

    {

    },
    {
      "index": 1,
      "relevance_score": 0.88,

## 语音合成接口

> 将文本转换为语音文件。

`POST /v1/audio/speech`

**参数**

表格

| **参数名**          | **类型** | **必填** | **描述**             |
| ---------------- | ------ | ------ | ------------------ |
| model            | string | √      | 语音合成模型名称           |
| input            | string | √      | 合成文本               |
| voice            | string | √      | 音色名称               |
| response\_format | string | ×      | 音频格式，如 `mp3`、`wav` |
| speed            | number | ×      | 语速                 |
| pitch            | number | ×      | 音调                 |

**请求示例**

```
{
  "model": "tts-model",
  "input": "欢迎使用 Herdsman 语音合成服务。",
  "voice": "female-01",
  "response_format": "mp3",
  "speed": 1.0,
  "pitch": 1.0
}
```

**响应示例**

```
{
  "object": "audio",
  "url": "",
  "b64_audio": "SUQzBAAAAAA...",
  "model": "tts-model"
}
```
