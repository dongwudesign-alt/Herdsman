# 网关基础地址 & 鉴权 KEY｜简单功能文档

## 模块概述

用于配置网关监听地址、管理访问鉴权密钥，控制服务监听端口、网络访问权限、API 调用身份校验。

## 1. 基础地址配置区

表格

| **控件**  | **功能说明**                                                                             |
| ------- | ------------------------------------------------------------------------------------ |
| 基础地址输入框 | 填写网关监听地址，示例 `http://127.0.0.1:16621`；填写`http://0.0.0.0:端口`开放局域网访问，管理界面依旧使用 127.0.0.1 |
| 应用按钮    | 保存地址配置，**执行后自动重启网关**生效                                                               |
| 刷新按钮    | 读取并刷新当前网关运行状态                                                                        |
| 重启网关按钮  | 手动触发网关服务重启                                                                           |
| 状态提示行   | 展示连通状态、监听地址、进程 PID；绿色「已连通」代表网关正常运行                                                   |

> 提示文案：填写 [http://0.0.0.0](http://0.0.0.0): 端口 可开放局域网访问；本机管理界面仍使用 127.0.0.1。应用后会自动重启网关。

## 2. 鉴权 KEY 列表区

表格

| **控件**  | **功能说明**                         |
| ------- | -------------------------------- |
| 新增按钮    | 创建一条新的 API 鉴权密钥                  |
| 表格‑名称   | 密钥别名；标记`内置`为系统默认 Default 密钥，不可删除 |
| 表格‑KEY  | API 请求鉴权 token 字符串               |
| 表格‑创建时间 | 密钥生成时间戳                          |
| 表格‑操作   | 对自定义密钥执行删除等操作；内置 Default 密钥无删除操作 |
