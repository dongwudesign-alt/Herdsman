# 模型调用看板｜详细功能文档

## 模块概述

**模块名称**：调用统计 - 模型调用看板

**归属导航**：左侧菜单栏「模型中心」→「调用统计」

**核心用途**：本地可视化统计模型调用请求量、成功率、错误、Token、延迟分布；**全部统计数据仅本地保存，不上传云端**。

## 1. 时间筛选区

表格

| **控件**   | **功能说明**                                |
| -------- | --------------------------------------- |
| 时间范围 Tab | 24 小时 / 7 天 / 30 天，切换统计窗口，所有图表、指标跟随窗口重算 |
| 刷新按钮     | 手动触发重新采集、渲染全部统计数据                       |
| 时间区间标签   | 展示当前筛选对应的起止时间戳                          |

## 2. 顶部指标卡片组

表格

| **指标**       | **释义**                                  |
| ------------ | --------------------------------------- |
| 总调用          | 周期内全部请求总数，附带标注成功调用数量                    |
| 错误率          | 失败请求占比；同时展示取消、失败请求计数                    |
| Tokens       | 汇总输入 Token 总量、输出 Token 总量               |
| P95 / P99 延迟 | 请求耗时分位值，单位 ms；P95 代表 95% 请求不超过该耗时       |
| TTFT         | 首 token 输出耗时，单位 ms；附带 TPS 每秒 token 输出速率 |
| 自动启动         | 流式、非流式自动启动的请求计数                         |

## 3. 请求趋势图表（折线统计图

* 图例：蓝色 = 请求量、红色 = 失败请求、黄色 = 平均延迟
* X 轴：时间轴；Y 轴：指标数值
* 业务逻辑：直观观测请求量波动、失败爆发点、延迟随时间变化趋势。

## 4. 摘要板块

### 4.1 运行时分布图表

* 按运行时（如 llama‑cpp、sd‑cpp）做调用量柱状统计；支持切换排序维度：**按调用量**。
* 展示不同后端运行时的请求负载分布。

### 4.2 能力分布

* 按接口 Endpoint 能力分类统计（chat19 对话、image‑generation2 图像生成）。
* 输出字段：总耗时 ms、消耗 Token 数量。

### 4.3 错误分布

* 按阶段 + 错误类型聚合统计调用失败记录；无错误时显示为空。

## 5. 模型排行板块

* 排序规则：**调用量降序**，展示最热模型。
* 每条条目展示：模型名称、总耗时 ms、消耗 Token 总数。

## 6. 按模型统计表格（底部表格）

> 将数据按模型名称聚合，完整明细表格。

表格

| **表格列** | **说明**          |
| ------- | --------------- |
| 模型      | 模型名称            |
| 调用      | 该模型总请求次数        |
| 成功率     | 成功请求占比          |
| 失败 / 取消 | 失败数量 / 用户主动取消数量 |
| 流式      | 流式请求计数          |
| 输入      | 该模型累计输入 token   |
| 输出      | 该模型累计输出 token   |
| 缓存      | 缓存命中 token 数量   |

## 业务规则

1. 数据存储：全部统计数据**本地持久化，不上传外部服务器**。
2. 数据刷新：切换时间窗口、点击刷新按钮，全量重新计算渲染图表与表格。
3. 空状态：周期内无调用、无错误时，对应图表 / 组件展示空数据。
4. 聚合逻辑：模型排行、明细表格均按模型名做聚合；能力分布按 API endpoint 聚合；运行时分布按后端 runtime 聚合。
