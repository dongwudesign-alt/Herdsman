# 路由模式配置项功能清单

## 一、策略（调度总开关）

1. **auto — 智能路由**：自动调度端侧 / 云端模型，下方「路由模式」参数生效
2. **edge — 全部端侧**：强制所有请求使用本地端侧模型
3. **cloud — 全部云端**：强制所有请求调用云端大模型
4. **cascade — 先端后云**：优先本地模型，本地处理失败自动降级云端

> ⚠️ 提示：仅策略选择 
>
> `auto`
>
>  时，右侧「路由模式」选项才会启用

## 二、路由模式（auto 策略下生效）

1. **single — 单路径**：固定单一模型链路，不做分支处理
2. **cascade — 级联**：串行调用模型（先本地，失败上云）
3. **split — 分流**：并行多路模型分发，可做多模型对比 / 投票

## 三、默认 Profile（智能路由倾向策略）

1. **economy — 更多端侧**：优先本地运行，节省云端资源
2. **balanced — 均衡**：端侧、云端调用比例平衡（默认）
3. **premium — 更多云端**：偏向调用云端，追求更强能力
4. **privacy — 尽量端侧**：最大限度本地推理，保护数据隐私

## 四、端侧上下文上限

`32768`：限制本地端侧模型单次对话最大上下文 token 长度
