# 技能详情面板功能清单

## 头部信息区

1. 技能名称：`herdsman‑api‑doc`
2. 来源标签：内置，显示本地文件路径
3. 启用开关：控制技能启停，状态显示「已启用」
4. 打开目录：跳转技能本地文件夹
5. 复制路径：复制技能目录路径

## 依赖与凭据

* 展示技能环境凭据声明状态；当前：该技能未声明环境凭据

## SKILL.md&#x20;

1. 只读提示：内置技能只读
2. 预览编辑区：展示 SKILL.md 元数据与指令文本&#x20;
   1. name、description 技能元信息
   2. 技能业务触发条件、执行指引、代码示例
3. 保存 SKILL.md 按钮：保存修改后的配置文件

### 表格汇总

表格

| **配置项**     | **类型** | **说明**            |
| ----------- | ------ | ----------------- |
| 启用开关        | 开关     | 开启 / 关闭该技能        |
| 打开目录        | 按钮     | 打开技能本地文件夹         |
| 复制路径        | 按钮     | 复制技能目录完整路径        |
| 依赖与凭据       | Tab 页  | 查看该技能所需环境凭据       |
| SKILL.md    | Tab 页  | 查看 / 编辑技能定义元文件    |
| 保存 SKILL.md | 按钮     | 保存 md 文件修改，内置技能只读 |
