# 技能面板功能清单

## 模块概述

分为「我的技能」「技能广场」子页面。

### Skill 策略

1. **启用 Skill 系统**（开关）：技能总开关，控制整套技能功能
2. **监听本地 Skill 文件变化**（开关）：自动检测本地 skill 文件修改并更新

### 我的技能（本地已安装）

* 搜索框：检索已安装技能
* 分类标签：全部 / 自定义 / 内置 / SkillHub
* **导入技能下拉按钮**&#x20;
  * 从文件夹导入
  * 从 ZIP 导入
* 筛选下拉&#x20;
  * 全部来源：User / Workspace / Bundled
  * 全部依赖状态：可用 / 需要设置
  * 有效：过滤技能生效状态
* **刷新**：重载技能列表
* 用户目录：展示技能本地存储路径
* Runtime 运行时信息栏：展示内置依赖版本（uv、node、pnpm、git、ffmpeg），支持刷新
* 技能卡片：展示技能名称、来源、简介；独立开关启停；更多操作菜单

### 技能广场（在线市场）

* 搜索框：检索线上技能库
* SkillHub 官网跳转链接
* 分类标签：全部、Pay Skill、办公效率、内容创作、开发编程、数据分析、设计多媒体、AI Agent 等
* 排序：综合 / 下载最多 / 最新
* 技能卡片：版本、评分、下载量、标签、简介；**安装**按钮拉取技能到本地
