# 本地模型商店界面‑功能清单

​

## 一、左侧全局导航栏

1. **模型中心（当前选中）**：模型浏览、下载、安装、管理主页面
2. **性能测试**：对已加载模型执行性能基准测试
3. **接口文档**：查看本地模型调用 API 接口说明文档
4. **调用统计**：统计模型调用次数、资源消耗等运行数据

# 二、右侧模型商店

## 顶部区域

**搜索框**：根据模型名称、描述、标签检索过滤模型列表。

**模型分类标签栏**

* 对话 / 语言
* 多模态
* 视觉语言
* 图像生成
* 语音合成
* 语音识别
* 向量嵌入
* 重排序
* OCR
* 文档处理
* NPU 系列模型 (WinML)

**​**

## 模型卡片通用信息项

每个模型卡片展示：

1. 模型名称 + 版本
2. 性能标签：速度等级（快 / 中）、显存占用大小 (GB)
3. 能力标签：多模态 / 对话 / 语言 / 推理 / 多语言等能力标识

## 卡片操作按钮

* **查看详情**：点击卡片打开模型详情页面，查看参数、介绍
* **下载模型**：仅未安装模型可用，下载模型到本地。已下载的按钮要给出标识，不可再次下载

## 模型列表区域

网格布局渲染模型卡片，支持垂直滚动浏览模型库；同时受【顶部分类、【搜索框】双重条件过滤显示结果。
