# 记忆面板 功能清单

### 记忆策略

1. **启用长期记忆**（开关）：全局开关，控制记忆功能总开关
2. **成功任务后自动抽取**（开关）：任务执行成功后自动生成记忆片段
3. **每轮预加载数量**（数值输入）：每轮对话前置读取记忆条数，默认 12

### 记忆列表筛选区

* 作用域标签：`全部` / `User` / `Workspace`
* 搜索框：检索记忆内容
* 状态筛选下拉：有效 / 已删除 / 全部
* 类型筛选下拉：全部类型 / Fact / Episode
* 来源筛选下拉：全部来源 / 手动 / 自动抽取
* **+ 新增**：唤起新增记忆弹窗

### 新增记忆弹窗

* 作用域单选：`User` / `Workspace`
* 内容输入框：
* 主题：多标签，逗号分隔
* 记忆类型：`Fact`（事实） / `Episode`（事件片段）
* 置顶开关：标记优先加载
* 按钮：取消、保存
